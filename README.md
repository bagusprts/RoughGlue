# RoughGlue

RoughGlue is a Real-time data processing Gateway Service utilizing Geo-enabled Machine learning integration frameworks.

RoughGlue is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- RoughGlue is a Real-time data
- processing Gateway Service utilizing Geo-enabled
- Machine learning integration frameworks

- Machine learning integration frameworks

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughGlue.git`
2. `cd RoughGlue`
3. Install in editable mode: `pip install -e .`

## Configuration

RoughGlue is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
